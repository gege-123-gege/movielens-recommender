## 三、追加：自己实现小版 ItemCF（约 45～60 分钟）

学习记录已取消。改为完成 `exercises/itemcf_practice.py` 中的 `score_candidates()`，用两层循环体验邻居数怎样影响推荐分数。

```powershell
notepad .\exercises\itemcf_practice.py
.\run.ps1 practice-itemcf
```

输入是历史电影列表、已排序的相似邻居字典、邻居数 n。先从每部历史电影取前 n 个相似邻居，再过滤历史中已有的候选，并把相似度累加到结果字典。

例如历史为 A、B：A 的邻居是 C=0.9、D=0.8；B 的邻居是 D=0.7、C=0.5。

- n=1：C 得 0.9、D 得 0.7，C 排在前面。
- n=2：C 得 1.4、D 得 1.5，D 排在前面。

新知识是字典累加：`scores.get(movie_id, 0)` 表示取出已有分数；尚不存在时取 0。例如 `scores[movie_id] = scores.get(movie_id, 0) + similarity`。先自己按文件中的五步提示实现，再对照检查结果排错。

检查工具有四个例子：取前一个邻居、取前两个邻居、只有一部历史电影、过滤已喜欢电影。这里使用给定的人造相似度，不代表真实数据实验。
