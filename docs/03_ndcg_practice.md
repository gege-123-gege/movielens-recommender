## 任务一：理解并实现 NDCG（约 50～65 分钟）

Recall 只统计找回多少部喜欢的电影。NDCG 还考虑它们的排名：喜欢的电影越靠前，得分越高。本项目采用二值相关性，属于验证集正反馈则相关，否则不相关。

例子：验证答案为 `{D}`，推荐 `[D, C]` 与 `[C, D]` 的 Recall@2 都是 1，但前一种顺序更好。

命中的第 position 名贡献 `1 / log2(position + 1)`，未命中贡献 0。前三名的命中奖励分别约为 1、0.63093、0.5。把奖励加起来就是 DCG。

IDCG 是同一份答案在前 K 个位置能得到的理想 DCG：把所有喜欢的电影尽量放在前面，共 `min(k, len(targets))` 个命中。NDCG = DCG / IDCG。理想得分依据验证答案计算，不能只数实际命中的数量。

先手算 `[D, C]`、`[C, D]`，答案为 `{D}`、K=2 时的 NDCG，再实现：

Python 提示：`enumerate(recommendations[:k], start=1)` 会同时给出从 1 开始的名次与电影编号。`range(1, ideal_count + 1)` 生成从 1 到 ideal_count 的整数。
