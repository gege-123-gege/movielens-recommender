## 2. 构建两份用户历史（约 60～75 分钟）

实现同一文件中的 build_profiles(rows, threshold=4)。本次先写普通字典、集合、循环和 if，不要求掌握 NumPy。

输入：

```python
rows = [
    (1, 10, 5.0, 100),
    (1, 20, 2.0, 110),
    (1, 30, 4.0, 120),
    (2, 20, 3.0, 130),
]
```

预期返回：

```python
seen = {1: {10, 20, 30}, 2: {20}}
positives = {1: {10, 30}}
```

seen 用来过滤所有已评分电影；positives 用来提供喜欢的历史，参与相似邻居打分。用户 2 没有达到 4 分的记录，所以不出现在 positives 中。

新语法：`set()` 创建空集合，`{}` 创建空字典。`seen[user_id].add(movie_id)` 把电影加入该用户的集合，前提是先为新用户创建集合。不要让所有用户共用同一个集合。

```powershell
.\run.ps1 practice-data --part profiles
```

验收：4/4，包含不同阈值、空输入、全部低分的情况。
